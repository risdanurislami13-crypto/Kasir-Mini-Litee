Cara Menjalankan Aplikasi :
1.	User membuka aplikasi kasir mini lite  pada perangkat(device) Android.
2.	Pengguna melakukan login menggunakan email/username dan password atau menggunakan akun Google.
3.	Setelah login berhasil, pengguna akan diarahkan ke halaman utama aplikasi (Home).
4.	Pada halaman Home, pengguna dapat melihat beberapa menu yang tersedia termasuk ringkasan keuangan
5.	Untuk melakukan input penjualan masuk ke menu penjualan
6.	Hasil inputan  yang ditambahkan akan tersimpan secara otomatis ke Firebase Realtime Database.
7.	Jika ada pengeluaran dari usaha user dapat menginputnya di menu pengeluaran
8.	Setelah selesai menggunakan aplikasi, pengguna dapat melakukan logout melalui menu  pengaturan
